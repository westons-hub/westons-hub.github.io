How it works


Three steps, all on one screen.


    

  1. 1
    Add your data
    Drop in CSV or Excel files. Query reads them and helps you clean up the messy ones.
    2. 

  2. 2
    Ask a question
    Build it by picking from menus, or write SQL yourself. Either way, you can see the SQL behind your question.
    3. 

  3. 3
    Get the answer
    The result shows up as a table you can sort and read right away.
    4. 



Private by design. Query runs entirely in your browser with DuckDB. There is no server, no tracking, and your files never leave your computer.
